# Проверка доступных записей TriggerBot

Внешняя разметка предоставлена пользователем; она не вычисляется по регулярности
атак. `OmL9iV1QdE` — Smart, включённый все 60 секунд; для `aNWxnnt1uR`
указана игра с TriggerBot, но режим и длительность включения не уточнены. Две остальные
записи отмечены как отрицательные. Исходные отчёты остаются локально в `build/`.

| Запись | Разметка | Сборка | Атаки наблюдателя / строки атак | Наблюдаемые тики / все тики | Напечатанные снимки до атаки | Напечатанные эпизоды |
| --- | --- | --- | ---: | ---: | ---: | --- |
| `JXFWbk26nY` | Отрицательная | simfix15 | 224 / 51 | 0 / 9410 | 32 из 64 сохранённых | 0 |
| `opSlMcFDhj` | Отрицательная | simfix15 | 0 / 0 | 0 / 11514 | 0 | 0 |
| `OmL9iV1QdE` | TriggerBot Smart | simfix17 | 47 / 47 | 1097 / 1195 | 0 | 0 |
| `aNWxnnt1uR` | TriggerBot, режим не указан | simfix18 | 138 / 101 | 2586 / 3479 | 32 из 64 сохранённых | 2, оба UNKNOWN |

У `aNWxnnt1uR` детектор допускал только 77 тиков; первой причиной исключения
были `jump-input` на 2027 тиках и `airborne-or-vertical-motion` на 215 тиках.
Геометрические счётчики: INSIDE=122, OUTSIDE=564, UNKNOWN=1431; причины UNKNOWN:
`no-guaranteed-box`=614, `uncertain-ray`=816, `block-in-visibility-prism`=1.
Это образцы целей, а не тики. Из 32 напечатанных снимков 24 имеют `onGround=false`.
В simfix18 зафиксировано 0 кандидатов и 0 принятых флагов TriggerBot.

Строки событий ограничены кольцевым буфером, поэтому их количество не всегда
совпадает с числом атак наблюдателя. В двух положительных записях медиана
интервалов между доступными строками атак — 600 мс, MAD — 1 мс. Это описание
времени прихода запросов; оно не доказывает автоматизацию. Sprint reset бывает
при ручной игре. `lastActualMovementY` — последнее наблюдавшееся перемещение,
не текущая вертикальная скорость клиента; `jump=true` — ввод, не положение в воздухе.

Полноценный replay новой проверки по этим отчётам невозможен: нет непрерывной
истории геометрии целей, готовности атаки и возможностей без удара, полного
порядка пакетов и состояния мира. Ограниченные Simulation/NoSlow traces не
восстанавливают эту историю. У отрицательных записей все тики были исключены
старым наблюдателем; `opSlMcFDhj` дополнительно не содержит атак. Поэтому эти
отчёты не измеряют ни полноту обнаружения, ни частоту ложных срабатываний.

Воспроизводимый аудит без Gradle, зависимостей и записи файлов:

```text
python tools/triggerbot_recording_audit.py --verify-known
```

[Инструмент](../tools/triggerbot_recording_audit.py) печатает JSON с SHA-256,
внешней разметкой, счётчиками, описательной статистикой и ограничениями данных.
Можно передать явные пути отчётов. `--verify-known` проверяет контрольные
количества четырёх записей и число напечатанных снимков; это проверка покрытия
и разбора формата, а не прогон алгоритма детекции. Неизвестные поля отсутствующей
диагностики выводятся как `null`, а не как нулевые измерения.
